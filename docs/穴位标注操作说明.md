# 三维人体穴位标注操作说明

## 1. 项目目标

本项目基于 BodyParts3D 4.0 成年男性参考人体，制作可在网页中旋转、缩放、搜索和分经显示的中医经穴学习工具。

技术栈：

- React
- TypeScript
- Three.js
- Vite
- GitHub Pages

主要定位依据：

- GB/T 12346—2021《经穴名称与定位》
- 模型：BodyParts3D 4.0
- 主要皮肤部件：FJ2810 / Skin
- 坐标单位：米
- +X：受试者左侧
- -X：受试者右侧
- +Y：上方
- +Z：人体前方
- -Z：人体后方

## 2. 准确性原则

### 2.1 不允许的做法

1. 不得根据穴位名称凭印象生成坐标。
2. 不得把旧经络示意线吸附到皮肤后称为准确路线。
3. 不得用全身高度除以75代替所有身体分区的骨度分寸。
4. 不得把相邻穴位简单等距排列，除非国标明确规定该区段的折量关系。
5. 不得默认人体左右完全镜像。
6. 不得把穴位顺序连线称为完整经脉循行。
7. 不得把“贴在皮肤上”写成“已经医学复核”。
8. 不得覆盖已经人工标注的数据，除非明确备份并确认覆盖范围。

### 2.2 每个穴位必须记录

- 穴位代码
- 中文名称
- 所属经脉
- 国标条款
- 国标定位正文
- 模型三维坐标
- 皮肤部件编号
- 皮肤三角面编号
- 三角面顶点编号
- 重心坐标
- 标注方法
- 标注状态
- 备注

### 2.3 状态定义

- `unplaced`：只有名称，没有三维位置
- `draft`：已放到皮肤，但定位尚未核查
- `self-checked`：已根据国标和解剖结构自行检查
- `expert-reviewed`：已经针灸专业人员复核
- `rejected`：位置有问题，不得用于正式显示

没有专业复核记录时，不得标记为 `expert-reviewed`。
